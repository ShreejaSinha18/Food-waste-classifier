# Food-waste-classifier
A deep learning model that classifies food waste and other organic wastes from a set of garbage.

**Dataset**
The HyperAI dataset (ID: 32410) provides a solid foundation for your food-waste classification pipeline. With a dedicated organic waste category that includes eggshells, tea bags, and coffee grounds, it directly supports your key use cases.
The dual “default” vs. “real_world” structure offers a great testbed for model robustness.
While it lacks fine-grained or location annotations, it’s an excellent resource to bootstrap model training—especially if complemented with other datasets for detailed detection and segmentation.

Link - https://hyper.ai/en/datasets/32410
